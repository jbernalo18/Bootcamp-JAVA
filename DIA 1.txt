Alojamiento web vs Alojamiento en la nube. 
La diferencia está principalmente en cómo se alojan y administran los recursos.

🌐 Alojamiento web tradicional
Es cuando contratas un espacio en un servidor para publicar tu página o aplicación web.
Tienes una página web → la subes al servidor → los usuarios entran mediante Internet.

☁️ Alojamiento en la nube
Tu aplicación se aloja utilizando infraestructura distribuida de un proveedor cloud, como AWS, Azure o Google Cloud.
Puedes disponer de recursos de:
procesamiento
almacenamiento
bases de datos
redes
balanceadores
servidores virtuales
Y puedes aumentarlos o reducirlos según la demanda.

Alojamiento web:

“Te doy un espacio para publicar tu sitio web.”

Alojamiento en la nube:

“Te doy acceso a infraestructura y servicios informáticos que puedes utilizar y escalar según tus necesidades.”

dedicado
Tienes un servidor físico completo para ti.

🖥️ Servidor físico
└── Tu aplicación

No compartes los recursos principales con otros clientes.


compartido 
Varios clientes utilizan el mismo servidor físico.

🖥️ Servidor
├── Página A
├── Página B
├── Página C
└── Página D
Todos comparten los recursos del servidor.


VPS - Maquina virtual aislada 
Un servidor físico se divide mediante virtualización en varias máquinas virtuales.
🖥️ Servidor físico
├── 💻 VPS 1 → Tú
├── 💻 VPS 2 → Cliente B
└── 💻 VPS 3 → Cliente C

Cada VPS funciona como si fuera un servidor independiente, aunque físicamente comparte recursos con otros VPS.

Página pequeña → Compartido
Aplicación con necesidades propias → VPS
Proyecto grande → Dedicado / Cloud

Crear algoritmo preparar palomitas de maíz. 

1. Inicio
2. Tomar una olla.
3. Agregar 2 cucharadas de aceite.
4. Agregar el maíz para palomitas.
5. Encender la estufa a fuego medio.
6. Tapar la olla.
7. Esperar a que el maíz comience a explotar.
8. Mover la olla suavemente.
9. Cuando los estallidos sean muy pocos, apagar la estufa.
10. Destapar la olla con cuidado.
11. Preguntar: ¿Las palomitas son saladas o dulces?
12. Si son saladas: agregar sal al gusto.
13. Si son dulces: agregar azúcar al gusto.
14. Mezclar.
15. Servir las palomitas.
16. Fin
